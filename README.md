# Student Management System (Java + JDBC)

## Description
Student Management System is a console-based Java application that performs CRUD operations on student records using JDBC and MySQL. The project demonstrates database connectivity, secure SQL execution using PreparedStatement, and proper resource management with try-with-resources.

---

## Features
- Add student records  
- View all student records  
- Find student by ID  
- Update student details  
- Delete student records  
- Menu-driven console application
